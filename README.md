# dsh-vim

用键盘走完整个操作流程的插件，适用于 DeepSeek Harness Web / Desktop 客户端：滚动、切会话、进出输入框、改推理等级、换模型、重命名、归档、决定 Enter 发不发，每一步都有键。

行为变化按版本记在 [CHANGELOG.md](CHANGELOG.md)。

## 核心规则

插件只做一件事：**保证每一颗键在任何时刻都是活的。**

宿主会在四个时刻把光标塞进输入框：首次打开页面、切换对话、发完一条消息、一轮任务跑完。每次落地，`d` / `e` / `f` 都变成死键。插件挡住这四次：

- 你点了输入框、按了 `Tab`、或者按了 `空格`——你**要**它，插件不插手。
- 宿主自己塞进去焦点——插件**立刻还给页面**。
- 只认富文本编辑器（消息输入框）；设置页、侧边栏搜索这些面板自己的字段不碰。

这条规则是其余功能的前提。滚动则是另一条同样简单的规则：**`d` / `e` 滚鼠标指着的那个可滚窗格**，没有写死的侧边栏 / 正文选择器。

滚动的落点也有规则：**从看板点进一个已经跑完的会话**时，页面停在**最后一条你写的消息**处，往下读就是新增的回答；从任务窗、侧栏等别的入口进入，位置仍归宿主，不跳。正在跑的会话、以及宿主自己恢复过阅读位置的会话，也不在此列。这只是滚动位置，键盘焦点照上面的规则走。

## 键位

所有键都能在设置页改。

### 页面上的键（窗口关闭时）

| 键 | 作用 | 配置项 |
|---|---|---|
| `d` / `e` | 鼠标指着的窗格向下 / 向上滚动 | `downKey` / `upKey` |
| `空格` | 进入输入框；空着时再按一次 = 离开 | `focusKey` |
| `q` | 推理等级换下一档（只动等级，不动模型） | `effortKey` |
| `w` | 模型选择窗；窗内 = 确定切换 | `modelKey` |
| `j` | 打开 / 关闭看板（侧边栏「看板」是同一入口） | `boardKey` |
| `n` | 给当前对话记一条想法（打开看板并落焦到那张卡） | `noteKey` |
| `i` | 把当前对话放到看板；任务窗开着时作用于选中行 | `pinKey` |
| `Enter` | 输入框里：发送 / 换行 / 不做事 / 连按两下发送 | `sendMode` |
| `Ctrl/⌘+Enter` | 发送（宿主自己的键，任何档位下都有效） | — |

### 输入框的标题

输入框自己那一行（`+` 和权限/计划芯片所在的那一排）最前面、`+` 之前有一个标题框。写一行字按 `Enter`，这一行就落到**输入框最上面**，正文照常写在下面；发出去之后，标题就是这条消息的第一行。标题框里按 `Enter` 不会被当成发送，`Esc` 清空并离开，空着写就是普通输入——什么都不加。

标题跟着文字走，不另存：它是消息的一部分，刷新、换设备、模型读到的都是同一份，也因此不能事后单独改标题而不动消息。那一行不存在时（例如还没有打开任何会话）就没有这个框，其余功能不受影响。

### 任务窗里的键（`f` 打开）

| 键 | 作用 | 配置项 |
|---|---|---|
| `f` | 打开任务窗；窗内 = 前往选中对话（站在 `更多` 上 = 展开下一批） | `paletteKey` |
| `e` / `d` | 上移 / 下移选中项；`d` 会停在 `更多` 这一站上 | `paletteUpKey` / `paletteDownKey` |
| `r` | 重命名选中对话 | `paletteRenameKey` |
| `s` | 切换阶段：讨论 / 编码 / 检查 | `paletteStageKey` |
| `g` | 归档选中对话（正在跑任务的不会归档） | `paletteArchiveKey` |
| `o` | 前往选中对话（站在 `更多` 上 = 展开） | `paletteEnterKey` |

### 模型窗里的键（`w` 打开）

| 键 | 作用 | 配置项 |
|---|---|---|
| `w` | 确定，切换到选中模型及其档位 | `modelKey` |
| `e` / `d` | 上移 / 下移选中项 | `paletteUpKey` / `paletteDownKey` |
| `Shift`+e / `Shift`+d（或 `Shift`+↑ / ↓） | 把选中行换个位置 | 跟随上下键 |
| `Tab` / `Shift+Tab`（或 `←` / `→`、`q`） | 换推理档位 | `modelLevelKey` |
| `Esc` | 取消并关窗 | — |

固定键：窗内 `Enter` 确认、`↑` / `↓` 移动选区、`Esc` 关窗；输入框里 `Esc` 把焦点还给页面。窗内之外，`Esc` 不接管：正在跑的任务仍归宿主。

## 看板

看板是主区域里的一页：一块地方一个**目标**（默认工作区名，可改；点标题收起 / 展开面板，标题右侧的 ⋯ 里改名），会话横向排开，各自的想法卡排在下面——想法卡没归位时是一张纸（两行预览），一旦收进收件箱或挂到会话下面，就统一读成一行窄条——同一个圆角、高度、内边距，挂在会话下面的还保留它自己的按钮和目标颜色；每个目标底部还有一行**我**：把想法卡拖进这一行，就成了这个目标下「人做的事」，一行一条读，拖出来又回到纸上（收件箱现在也是同一块目标，只是它收的是谁也不归的东西）。想法卡上有一个锁：锁上之后整理不再移动它；分叉画肘线，空白处写自由的想法卡。面板、会话卡片、想法卡片都是不透明的，叠在一起时不会互相透出（拖动中的卡片也是）。想法卡只占两行预览，点一下会在画布中央打开一张大纸：标题和正文完整显示，直接在纸上编辑，输入即写回卡片；`Esc`、点纸外、`×` 或 `⌘/Ctrl+Enter` 收起。纸顶的完成勾选和纸底的「投入会话」照旧可用——投入不再把你跳进那条会话：文字排进它的草稿，下次打开它时自动放进输入框末尾，输入框里已经有字就另起一段，所以可以连着投好几张，按投的顺序落进同一个草稿；`⋯` 里还有「看全文」和其余操作。新建想法也从这张大纸开始：标题栏「＋ 卡片」或画布空白处双击；双击时纸从落点展开，写完（不为空）就落回双击的位置，点「取消」则不落地。托盘里的想法行同样打开这张纸。一条会话下的未完成想法全部显示，已完成的只显示三条、其余折成一行数量、点开再看。会话标题旁的**锁**一锁上，投入想法卡就不再改名，手动改名也会被拒绝。会话卡片上的 `⋯` 收着不常用的操作，改名就在里面；目标底部的 `+` 或它的名称那一行都能开一条新会话，两者都在后台建、不跳转：看板留在原地，新会话直接出现在这个目标下面，写下的正文（或拖上去的那张卡的字）作为它的草稿等着，第一次打开它时自动放进输入框。会话卡片分两栏：左边是标题（最多两行）和它下面那一行状态；右边是三行两列、固定六个图标位——锁、`⋯`、`★`、分叉、记一条、已完成列表，没有内容的位子留空也不移动别的图标，其余的动词（改名、从看板移除）在 `⋯` 里。状态跑着或刚跑完时是只读的；平时显示「任务状态」四个字，点开可以标「暂停中」或「已完成」；标「已完成」就是把它收进底部的「今日已完成」，标过的那一轮再动一次就自动作废。最下面那行工具整行都不进会话——按在状态槽、星标、分叉之间的空处也留在看板上，进入会话按卡片上半部分的名字或那行话；卡片不再画「N 轮」，那一格不占地方。卡片从上往下读三行：名字、这条会话里最近一次输入的第一句人话、它的状态；名字只留一行，第二行那点高度原来就为名字留着，所以卡片没有变高。那行话来自宿主自己的轮次大纲（`turnOutline`），已经是收成一行的一句，超出一行就省略，悬停看全文；还没说过话的会话占着这一行、什么也不写。目标里的会话保持面板记住的先后，新会话只接在末尾，不会因为刚动过就插到前面。每张卡片（目标和托盘）底部有一条「今日已完成 N」：默认收起，点开是今天收进去的会话卡片；把上面的会话卡拖到这条长条上就算今天完成，状态槽也会同时写成「已完成」；从长条拖出来、或把状态改成别的词，它就回到工作区，正在跑的会话也会自己回来。每个目标有自己的颜色：面板是同色薄染，会话卡同色加深、左边一道脊；标题旁的色点就是换色的按钮，点开十二色挑一个，这个目标从此用它，别的目标来去也不换。会话可以新建或分叉；看板每天封存一页历史：标题栏的「历史」打开一份日历，有页的日子下面有个小点，点一天画布就换成那天画的样子（只读，改不了），左上角的横条和 Esc 都能「回到今天」；历史可以导出 / 导入。一个目标的会话横排到三列就换行，不再每多一条就宽出一列；带进来、今天没动过、也没在跑的那些，收在面板底部的「今天没动 N · 最久 N 天」里，点开是一行一条，行上写着它名下几张想法卡，点那个数字就把想法摆出来——按 ★、今天动一下，或把它拖回上面的工作区，它就回到列里。

标题栏的**整理**只管面板：按当前窗口宽度把收件箱和目标排成整齐的几行——收件箱固定在画布左上角，其余面板按原来的先后从它右边、下面接着排，面板与面板、行与行之间留同样的空隙；想法卡停在它们原来的位置，不会被收走（锁上的卡片，整理连挪都不挪）。已有位置已经整齐，或目标太多一屏放不下时，它会继续往下排，不会缩掉任何一块。重新打开看板时，如果哪个目标因为多了会话卡片而和邻居叠在一起，它会自己按同一套规则排一次，不用再按「整理」——这一步只挪面板，不会把没连会话的想法收走。缩放组最右边的方形标记是**按窗口大小**：把整块画布缩放到看板自己的区域能看全——宽度或高度装不下就继续缩小，已经装得下就保持 100%；窗口或侧栏再变宽变窄都会跟着重新适配。按 `+` / `−` / 100% 或 `Ctrl/⌘ + 滚轮` 就交回手动。

标题栏最右边的**设置**打开看板自己的几个开关，第一个是**会话标题自动修改**：开着时看板才会自己改会话标题——分叉出来的新会话会改成一个不和别人重名的名字，想法卡交给某条会话时按卡片第一行给它命名；关掉后看板不改任何标题。被锁住的标题两种情况都不动。

想法卡会记下**写下**和**办掉 / 投出**两个时刻，写进看板文档；看板另有一条只追加的日志（独立 IndexedDB），记下写下、投进、办掉、跑完线程、新开对话。每天第一次打开看板，先给一屏**昨天的一天**：写下几张、投出去几张、跑完几条线程，以及今天还等你几件、承天几条——任意键收起，同一天不再出现。历史日历上面有一行搜索，拿一句话就能翻回它写在哪一天，点结果就直接把画布调到那一天。

细节以界面上的操作为准，键位见上表。

## 概览

概览是看板旁边的一页：看板标题最右边的**概览**按钮进这一页，侧栏里也有自己的一行；页头右上角的**回看板**按钮回去。

只读，只算**今天**：动过的目标几条、会话几条，今天办掉几张想法卡、写下几张。下面一行一条会话，写着它属于哪个目标、今天办掉几张、名下共几张、还没办几张；按目标排，同一个目标里今天办得多的在前。会话按「今天动过」算——昨天带进来、今天没再动的那些不上这一页，和看板底部的「今天没动」不是一回事。还躺在纸上、没连到会话的想法单独一行列出来，不混进会话的数字。

想法卡的两个时刻各算各的：昨天写下、今天办掉的，昨天记一笔写下，今天记一笔办掉。

## 设置

设置 → **Vim 滚动**，改动即时生效，不需要重启。

- **快捷键**：见上表。
- **常用模型**：从宿主模型目录里勾选并排序，`w` 的窗按这个顺序列。读不到目录时会写明原因。
- **焦点**：Esc 离开输入框、空格离开空输入框、不自动聚焦、发完消息交还键盘；以及 Enter 做什么。
- **弹窗**：字号 11–20 px、宽度 480–1400 px、高度 40–95 vh、行距、弹出位置。
- **滚动**：步长 40–600 px、缓动 10–250 ms、连发延迟 80–800 ms。

配置存在 localStorage 的 `dsh-vim/settings/v1`，跟着设备走，升级插件不会清掉。

## 安装

`desktop` profile 由 Electron 应用独占，走应用内的插件管理器：

1. 侧边栏 → **插件** 页
2. **安装组合包**，spec 填本仓库的绝对路径
3. 若未立即生效，重启 DSH Desktop

其他 profile（如 `web`）可以直接用 CLI：

```sh
dsh plugin --profile web add "G:\桌面\dsh-vim"
```

本包没有任何依赖、没有 install/build 脚本，不需要 pnpm 的 `allowBuilds` 授权。

## 结构

```
dsh-vim/
├── package.json        dsh.bundle.patch + dsh.client
├── cordis.patch.yml    insert 一行 dsh-vim，让 Loader 挂载本插件
├── dsh.plugin.json     插件管理器展示用的清单
├── lib/
│   ├── index.js        Host 面：空壳 apply
│   └── client.js       浏览器面：全部逻辑
├── tools/
│   ├── selftest.mjs    假 DOM + 虚拟时钟的行为断言
│   └── probe.patch.yml 不落盘的合成验证 overlay
└── MAP.md              client.js 顶层函数索引（npm run map 生成）
```

没有构建步骤：`lib/` 是手写的、可直接运行的 JS，唯一 `require()` 是 `react`。设置页用 `createElement` 手写，任务窗是纯 DOM + 内联样式，零依赖。


| `__dshVim.board()` / `board(true)` | 看板状态 / 直接打开 |

## 已知限制

- **Enter 默认仍是发送**。只有主动切到其他档位，裸 Enter 才不发送；此时输入框下方有一句提示，提示挂在宿主的 `conversation.composer.dock` 槽上，那一行不存在就没有提示（功能不受影响）。
- **双 Enter 档占用「连按两下 Enter 空一行」的手势**，误发不可逆。想空行用两下 `Shift+Enter`，或两下裸 Enter 之间停超过 250ms。
- **iframe 内收不到按键**，按在 iframe 里也关不掉任务窗 / 模型窗，得按 `Esc`。
- **不自动聚焦只认富文本输入框**（Lexical）；换成 `textarea` 的宿主上这条规则失效。空格进输入框依赖 `[data-lexical-editor="true"]` 或已见过的那个元素。
- **任务窗没有搜索框**，3 小时窗口与每批 20 条是写死常量；更早的对话要点 `更多`。
- **摘要记的是动作，不是时长**：想法卡的两个时刻从 0.50.0 才开始写，旧卡没有，所以它们不会出现在任何一天的摘要里；摘要和历史搜索都靠看板自己的数据库，宿主不给独立数据库时这两样不出现，看板照常；搜索最多读最近 200 页，并会写明读了多少。
- **想法、阶段、看板排列只存在这台设备的 localStorage**（`dsh-vim/notes/v1`、`phases/v1`、`board/v1`），不跟账号，清站点数据就没了；换端口（origin 变了）也看不到。一条对话只能挂一句话。
- **看板页需要宿主的侧边栏页座位**（`main` + `sidebar.panellist`）；没有时 `j` 退回悬浮窗。看板没有键盘移动卡片的手势，位置靠拖。
- **阶段是手动标的**，不会自动判断。
- **归档没有撤销、也没有确认框**；正在跑任务的对话按 `g` 不会归档，只会提示先停。归档当前屏幕上的对话会清空主视图（宿主行为）。
- **换模型会在下一条请求前插入宿主自己的提示**（`[model changed: …]`），可能减少缓存复用；推理等级只改当前这条对话。
- **不注册进 `ctx.shortcuts`**，不出现在快捷键速查、也不参与冲突校验；只支持单字符键。
- **任务窗或模型窗开着时 `e` / `d` 归它**。想两者同时拥有，把窗的上下键改到 `j` / `k`。
- **计时从插件看到「开始跑」那一刻算**，起点超过 12 小时不认。
- **看板分叉线只认这个客户端亲眼看到的分叉**；之前存在的分支当作独立会话，不伪造连线。
- **改动 `lib/client.js` 后需要重启进程**，运行中的模块不会热替换。
